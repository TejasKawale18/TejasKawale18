# 🚀 Featured Project

## 🧠 AI Powered Math Notes Assistant

> A multimodal AI-powered mathematical learning assistant capable of understanding **text, images, voice and handwritten mathematical expressions**.

### ✨ Highlights

- ✍️ Handwritten mathematical expression solving
- 🖼️ Mathematical problem solving from images
- 💬 Conversational AI assistant
- 🎤 Voice-based mathematical queries
- 🧠 Gemini 2.5 Flash multimodal reasoning
- 📚 Step-by-step educational explanations
- ➗ LaTeX/MathJax mathematical rendering
- 🌐 Flask-based backend
- ☁️ Deployed on Render

🔗 **[View Project](https://github.com/TejasKawale18/AI-Powered-Maths-Notes-Assistant)**  
🌐 **[Live Demo](https://ai-powered-maths-notes-assistant.onrender.com)**
